MANAGE CONFIGURATION

Stage 01 · Data quality

Validate receipt identityvalidate_receipt_identity v1
Canonical
Purpose
Checks that each canonical report carries a valid receipt business identity (message reference, reporting entity, period).
Inputs
Canonical report headers · no parameters
Output
Findings with code RECEIPT_IDENTITY_INVALID (error)
Example
A report whose reporting entity ID is blank is flagged and will be rejected at a DQ gate blocking on errors.
Detect duplicate reportdetect_duplicate_report v1
Canonical
Purpose
Finds reports sharing the same canonical business key.
Output
DUPLICATE_BUSINESS_KEY (error) on each duplicate

Stage 03 · Data quality

Resolve entityresolve_entity v1
Canonical · DQ passed · Enriched
Purpose
Matches each constituent entity to the domestic entity register using identifiers and name similarity.
Parameters
match_confidence_floor number 0–1, default 0.85 — entities below the floor are reported as unresolved
Output
Resolved entity references in the run summary; ENTITY_UNRESOLVED (warning) findings
Typical use
Run on the DQ-passed snapshot before enrichment so that enrichment facts can be attached to resolved entities.
