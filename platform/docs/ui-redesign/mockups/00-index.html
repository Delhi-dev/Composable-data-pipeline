Mockup index. Static HTML/CSS/JS mockups for the simplified CbCR UI. They reuse the product's own stylesheets (base-niche.css and base-wip.css are verbatim copies of web/niche.css and web/wip-workbench.css) plus redesign.css for new components. The yellow bar switches persona (navigation is derived from roles) and theme. The accompanying document is ../UI_REDESIGN_PROPOSAL.md.

Shared components (see redesign.css / mock.js)

  • ID chip — click to expand, COPY to copy, tooltip holds the full ID
  • Stage stepper (horizontal and vertical) — done / current / future / blocked / skipped
  • Filter bar with scope segmented control, "More filters", active-filter chips and URL mirror
  • Accordion rows in tables (tr.summary + tr.row-detail) and cards (.run-card .body)
  • Help icon i, callouts, empty states with a next action, next-action panel with prerequisites
  • Confirmation dialogs with a summary table (replaces window.prompt)
  • Technical details expander (<details>) that keeps raw JSON available but out of the way
