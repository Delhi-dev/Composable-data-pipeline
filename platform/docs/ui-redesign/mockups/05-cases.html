Glossary

Risk evidence set
The exact completed risk runs frozen as evidence. Draft → Approved. (API: risk-result set)
Selection batch
Candidates generated from one approved evidence set, awaiting human decisions.
Final case set
Immutable record of the candidates selected when a batch is finalised.
Audit handoff case
One durable case per selected candidate, worked outside this software.

An immutable Final case set containing the 5 selected candidates, and one Audit handoff case per selected candidate. Not-selected and deferred candidates are kept in the batch record for audit.
